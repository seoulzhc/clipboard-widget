剪贴板助手 · 使用说明
========================

一、它是什么
    一个常驻桌面的小面板，自动记录你复制过的文字，方便随时再粘贴。
    左边是「复制记录」，右边是「收藏」。

二、怎么用
    · 单击条目            → 把内容复制到剪贴板（面板底部会提示“已复制到剪贴板”）
    · 双击条目 / 点 ✎     → 编辑这条内容，改完点“保存”或按 Ctrl+Enter，Esc 取消
    · 点 ☆ / ★            → 收藏 / 取消收藏，收藏的内容会出现在右栏
    · 拖动四个角          → 整体等比缩放（和微信窗口一样拉边角，0.6～1.6 倍，自动记住）
    · 顶部 −              → 收起到任务栏右下角的托盘（小鲸鱼图标那一排），点托盘图标恢复
    · 顶部 📌             → 置顶开关（默认置顶，点亮时一直浮在最上层）
    · 拖动标题栏          → 移动面板，位置会自动记住
    · 顶部 ✕              → 退出面板（托盘里也会一起去掉）

三、位置与数据
    · 默认停在屏幕右下角，关闭再打开会回到上次的位置
    · 数据保存在：C:\Users\Administrator\AppData\Roaming\ClipboardWidget\data.json
      （历史最多 60 条，收藏最多 200 条，都是本地保存，不上传）

四、开机自动启动
    已放入“启动”文件夹，登录 Windows 后会自动出现。
    不想自启：删除
      C:\Users\Administrator\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup\剪贴板助手.lnk
    也可以在「任务管理器 → 启动应用」里禁用它。

五、重新打开 / 关闭
    · 关闭后想再打开：双击桌面上的「剪贴板助手」快捷方式
    · 彻底不用了：删除桌面和“启动”里的快捷方式，再删除
      C:\Users\Administrator\Documents\deepseek-harness\default-workspace\clipboard-widget 文件夹
      以及上面的 AppData\Roaming\ClipboardWidget 文件夹

六、小提示
    · 只记录文字，不记录图片和文件
    · 密码等敏感内容也会被记录，注意及时删除（编辑成空会保留原样，建议直接不复制敏感信息）
    · 程序由 Windows 自带的 PowerShell 运行，不需要额外安装任何东西
